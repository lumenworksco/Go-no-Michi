# Security policy

ごのみち is a static, offline-capable web app. It has no server, no accounts and no network requests
other than loading its own files. The only data it stores is in your browser's `localStorage`
(game in progress, settings, win/loss record, solved puzzles).

If you find a security problem, please report it privately through GitHub's
**Security → Report a vulnerability** on this repository rather than opening a public issue.
Only the latest version deployed at https://go.braunf.com/ is supported.
